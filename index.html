옆집 싸움구경

매우 폭력적이고 자극적인 난투극 (농담이에요)

조그만 버섯들이 동네 한복판에서 뿅망치와 물총으로 서로를 튕겨 냅니다. 친구 최대 4명과 참가 코드 하나로 바로 같이 놀 수 있어요.

Windows용 다운로드
무료 · Windows 10/11 (64비트) · v0.1.0 · 약 54 MB

설치하고 실행하기

1

내려받기

위의 노란 버튼으로 TheyFight-Windows.zip 을 받아요.

2

압축 풀기

zip 파일을 오른쪽 클릭 → 압축 풀기. 바탕화면 같은 편한 곳에 풀어 주세요.

3

실행

풀린 TheyFight 폴더의 TheGame.exe 를 실행해요.

"Windows의 PC 보호" 창이 뜨면 → 추가 정보 → 실행을 눌러 주세요. 개인이 만든 게임이라 서명이 없어서 나오는 안내예요.
방장이 처음 방을 만들 때 방화벽 허용 창이 뜨면 허용을 눌러 주세요.

친구와 같이 놀기

1

방 만들기

한 명이 메뉴에서 방 만들기! 를 눌러요. 이 사람의 PC가 방이 돼요.

2

참가 코드 보내기

화면 왼쪽 위의 참가 코드를 친구에게 보내요. Esc 화면의 코드 복사 버튼도 있어요.

3

참가하기

친구는 코드를 입력하고 참가하기. 포트 열기나 IP 설정은 필요 없어요.

모두 같은 버전이어야 같은 방에 들어갈 수 있어요. 새 버전이 나오면 다 같이 다시 받아 주세요.

조작법

WASD이동
마우스둘러보기
Shift달리기
Space점프
좌클릭공격 (물총은 누르고 있기)
1 · 2 · 휠뿅망치 / 물총 바꾸기
E통·상자 잡기 / 던지기
Tab점수판
Esc일시정지 (감도, 소리 크기)

게임패드도 돼요.

규칙

목표상대를 KO 시켜서 KO 수를 올리기
뿅망치앞쪽 상대를 크게 튕겨 내요 (15 데미지)
물총약하지만 계속 쏠 수 있어요. 물은 우물 근처에서만 다시 차요
통·상자잡으면 방패, 던지면 무기
버섯 점프대밟으면 지붕까지 날아가요
자동차경적이 울리면 피하세요!
주민하얀 양송이 주민은 맞으면 도망가요 (점수와 무관)
